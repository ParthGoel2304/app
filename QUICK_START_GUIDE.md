# 📱 Excel Reader App - Quick Start Guide

## ✅ Step 1: Your Google Drive is Ready! ✓

Great! You've linked your Google Drive (partharjun04@gmail.com) with Excel. Now let's set up your Excel files:

---

## 📤 Step 2: Upload Your Excel Files to Google Drive

### Method 1: Using Google Drive Website (Easiest)
1. Open your browser and go to: **https://drive.google.com**
2. Sign in with: **partharjun04@gmail.com**
3. Click the **"+ New"** button (top left)
4. Select **"File upload"**
5. Choose your Excel file (.xlsx)
6. Wait for upload to complete ✓

### Method 2: Using Google Drive Desktop App (For Auto-Sync)
1. Download: **https://www.google.com/drive/download/**
2. Install and sign in with: **partharjun04@gmail.com**
3. Create a folder called **"ExcelFiles"** in Google Drive
4. Save/copy your Excel files to this folder
5. They will auto-sync whenever you save! 🔄

---

## 📱 Step 3: Using the Mobile App

### A. Open the App
- **Web Browser**: https://inventory-lookup-app.preview.emergentagent.com
- **Mobile Device**: Scan QR code or visit the URL

### B. Connect Google Drive
1. You'll see the welcome screen
2. Tap the big blue **"Connect Google Drive"** button
3. Sign in with: **partharjun04@gmail.com**
4. Click **"Allow"** to give read-only access
5. You'll be redirected back to the app ✓

### C. Browse Your Excel Files
1. After connecting, you'll see all your .xlsx files
2. **Tap on any file** you want to read
3. The app will show you all sheets in that file

### D. Select Sheet and Range
1. **Choose a sheet** (e.g., "Sheet1")
2. **Enter cell range** (e.g., "A1:D10")
   - **A1:D10** = Reads rows 1-10, columns A-D
   - **B2:F50** = Reads rows 2-50, columns B-F
   - **A1:Z100** = Reads rows 1-100, all columns A-Z
3. Tap **"View Data"**

### E. View Your Data
1. Your Excel data appears in a scrollable table
2. First row is treated as headers (highlighted in blue)
3. Scroll horizontally/vertically to see all data
4. Tap **refresh icon** to sync latest changes

---

## 🔄 Step 4: Updating Excel Data

### When You Change Your Excel File:

1. **Save your Excel file** on your computer
2. If using **Desktop App**: It auto-syncs instantly ⚡
3. If using **Website**: Re-upload the updated file
4. **In the mobile app**: Tap the **refresh icon** (🔄)
5. Your data updates! ✓

## 🆘 Troubleshooting

### "No files found"
- Make sure you uploaded .xlsx files (not .xls or .csv)
- Tap the refresh button
- Check you're signed in with: partharjun04@gmail.com

### "Invalid cell range"
- Use format like: **A1:D10**
- Capital letters for columns
- Numbers for rows
- Colon (:) to separate start and end

### "Can't connect to Google Drive"
- Check internet connection
- Try disconnecting and reconnecting
- Make sure you clicked "Allow" during OAuth

### "Data not updating"
- Tap the refresh icon in the app
- Make sure Excel file is saved and uploaded to Drive
- Wait a few seconds for sync
